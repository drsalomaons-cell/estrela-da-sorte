# Estrela da Sorte

Fundação inicial do aplicativo sobre a arquitetura definida no dossiê.

## Titularidade e licenciamento

O projeto contém código e materiais originais desenvolvidos para o **ESTRELA DA SORTE**, além de componentes de terceiros.

- Os componentes originais do projeto são tratados como **proprietários**, conforme o arquivo [LICENSE](./LICENSE).
- Bibliotecas, frameworks, SDKs, serviços e demais componentes de terceiros continuam sujeitos às suas próprias licenças e termos.
- O repositório não concede automaticamente a terceiros direitos de redistribuição, sublicenciamento ou comercialização do código proprietário.
- Qualquer licença comercial, cessão ou autorização específica de uso será definida separadamente pelo titular.

## Base

- React + TypeScript + Vite
- Supabase para backend e permissões
- LiveKit para voz/vídeo
- Zustand para estado
- UI mobile-first

## Regra do projeto

Auditar → testar → comparar → propor → aprovar → alterar.

A economia 50/50 permanece em auditoria e não é alterada por esta fundação.
