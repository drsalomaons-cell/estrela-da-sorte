# Estrela da Sorte

Fundação inicial do aplicativo sobre a arquitetura definida no dossiê.

## Base
- React + TypeScript + Vite
- Supabase para backend e permissões
- LiveKit para voz/vídeo
- Zustand para estado
- UI mobile-first

## Regra do projeto
Auditar → testar → comparar → propor → aprovar → alterar.

A economia 50/50 permanece em auditoria e não é alterada por esta fundação.
