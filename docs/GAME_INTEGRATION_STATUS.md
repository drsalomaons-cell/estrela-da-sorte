# Game integration status

The repository contains a 20-entry slot catalog. These entries are not yet 20 verified playable open-source games.

Status categories in game_registry:
- planned
- prototype
- integrated
- tested
- disabled

Before publication, each game must have:
- source repository and license recorded
- asset provenance recorded
- playable build integrated
- mobile performance checked
- coin/free mode behavior tested
- responsible-gaming and jurisdiction review where applicable

Open-source engines/examples may be used where licensing permits; public source alone does not mean a game is cleared for publication.
