# Economy governance

The economy is simulation/audit-first. No real-money payout is enabled by these migrations.

Roles: Super ADM, Official ADM, BD, Agency, Host.

Controls required before production:
1. Role approval and audit trail.
2. Explicit commission rules and versioning.
3. Simulation tests for each role chain.
4. Ledger reconciliation and idempotency.
5. Fraud/abuse limits and suspension workflow.
6. Legal/compliance review before real-money activation.

The repository records the economic structure without claiming production payouts.
